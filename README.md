# Factorial Stack Linked List

A simple C++ project that uses a linked-list-based stack to calculate factorial 6 (`6!`).

## Files

- `src/main.cpp` - pushes values 1 through 6 onto the stack and multiplies them.
- `src/Stack.cpp` - linked-list stack implementation.
- `include/Stack.hpp` - stack declarations.
- `include/node.hpp` - stack node structure.

## Build and Run

```bash
g++ ./src/*.cpp -o main
./main
```

The program prints:

```text
720
```
